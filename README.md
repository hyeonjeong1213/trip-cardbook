# ✈ TRIP CARDBOOK - 지역별 여행지 카드북

한국관광공사의 국문 관광정보 서비스 API와 Firebase를 활용한 지역별 관광정보 조회 및 여행지 찜하기 웹앱입니다.

## 1. 프로젝트 소개
사용자가 원하는 지역을 선택하면 해당 지역의 관광정보를 조회하고, 마음에 드는 관광지를 찜하여 개인 보관함에 저장할 수 있습니다.

## 2. 주요 기능
- 지역별 관광정보 조회
- 관광지 이미지 및 정보 카드 형태로 출력
- 관광지 찜하기 및 찜 취소하기
- 내가 찜한 관광지 보관함 조회
- Firebase Firestore를 이용한 데이터 저장

## 3. 사용 기술
- HTML5
- CSS3
- Vanilla JavaScript
- 공공데이터포털 OpenAPI
- Firebase Authentication
- Firebase Cloud Firestore
- GitHub Pages

## 4. 데이터 처리 흐름
공공데이터 조회 → 웹 화면 표시 → 사용자 활동 Firebase 저장 → GitHub Pages 배포
